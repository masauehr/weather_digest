# 気象ニュースダイジェスト（9/13〜9/20）

## 1. 台風25号が関東に接近・記録的大雨への警戒続く

9月21〜22日にかけて、台風25号が関東など東日本の太平洋側に接近することが予想されています。秋雨前線の影響が引き続き強く、大雨が懸念されています。気象庁によると、停滞する秋雨前線の影響で9月8〜9日には東海地方（愛知県・岐阜県）で線状降水帯が発生し、名古屋市では1時間に104.5mm という観測史上1位の猛烈な雨が降りました。8月の千葉豪雨で被災した地域への「追い打ち」となる降雨も懸念されます。

**参考:** [台風9号(2026年) | 日本気象協会 tenki.jp](https://tenki.jp/bousai/typhoon/2609/) / [NHKニュース「台風25号 21～22日ごろ関東などに接近予想」](https://news.web.nhk/newsweb/na/nd-20260918de51158)

## 2. 秋雨前線が長期停滞・9月は「残暑」と「大雨」が共存

気象庁の1か月予報によると、9月12日～10月11日の予報期間を通じて秋雨前線の影響が続き、曇りや雨の日が多くなる見込みです。一方、エルニーニョ現象の影響で暖かい空気が流入しており、東海から九州では9月後半でも最高気温が30℃以上の真夏日が続く地域がある予想。この「異常な残暑」と「秋雨による大雨」が同時に発生する異例の気象パターンが続く見通しです。

**参考:** [日本気象協会「2026年9月の天気予報｜厳しい残暑と大雨に注意」](https://weather-jwa.jp/news/topics/post15455) / [ウェザーニュース「気象庁1か月予報 しばらく秋雨続く」](https://weathernews.jp/news/202609/100121/)

## 3. Google DeepMind「WeatherNext 3」発表・AI気象予報が5km解像度へ進化

9月3日、Google DeepMindが新しいAI気象予測モデル「WeatherNext 3」を発表し、Google 検索・Geminiアプリ・Google マップに統合されました。従来の「WeatherNext 2」（6時間ごと、25kmグリッド）から、**1時間ごとに5km解像度で更新される高精度予報に進化**します。リアルタイム衛星観測を直接取り込み、短時間降水予報の精度が最大60%改善したことが特徴です。データはGoogle Cloud Storage・BigQuery・Earth Engineでも提供されます。

**参考:** [Google DeepMind「WeatherNext 3」](https://labmemo.com/google-weathernext3-ai-weather-forecast-5km-hourly-gemini-2026/) / [「降水予報が最大50%向上」- Impress Watch](https://www.watch.impress.co.jp/docs/news/2138283.html)

## 4. スーパーエルニーニョが継続・世界的な異常気象が深刻化

気象庁と世界気象機関（WMO）の観測によると、2026年春から発生したエルニーニョ現象は観測史上最強クラスの「スーパーエルニーニョ」に発展し、秋にかけて継続する見込みです。7月のエルニーニョ監視海域の海面水温の基準値からの差は+2.5℃で、1950年以降では1997年と並ぶ過去最大級となっています。WMOは「今後5年間の世界平均気温上昇は過去最高レベルとなり、産業革命前からの1.5℃上昇を超える確率が66%」と警告しており、世界的な異常気象（干ばつ・森林火災・高温）が懸念されています。

**参考:** [気象庁「エルニーニョ現象が発生しているとみられます」](https://www.jma.go.jp/jma/press/2606/10b/elnino202606.html) / [RIEF「世界気象機関（WMO）、世界の気温上昇は今後5年間で過去最高レベル」](https://rief-jp.org/ct8/135692)

## 5. 気象庁の新防災気象情報制度が5月から運用開始・警戒レベル統一で「わかりやすく」

2026年5月29日から、気象庁は新たな防災気象情報制度の運用を開始しました。これまで「警戒レベル」と「情報名」の対応が対象災害ごとに異なり「わかりにくい」という課題を解決するため、5段階の警戒レベルに統一されました。例えば「大雨警報」は「レベル3大雨警報」と表記され、情報に直接レベルの数字が組み込まれます。河川氾濫情報も整理され、大河川（全国約400河川）の「洪水予報河川」については「氾濫警報」が河川ごとに発表、中小河川は市町村ごとの「大雨警報」で対応することになりました。

**参考:** [気象庁「新たな防災気象情報について(令和８年～)」](https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/index.html) / [日本気象協会 tenki.jp「新しい防災気象情報が5月28日スタート」](https://tenki.jp/suppl/m_seta/2026/05/15/32805.html)
