# 気象ニュースダイジェスト（2026年6月）

2026年6月の気象・気候関連ニュースをまとめました。

## 今週の注目トピック（5/31〜6/7）

### 1. WMO：エルニーニョ現象発生確率80％、9月以降は90％超に

世界気象機関（WMO）は6月初旬、エルニーニョ/ラニーニャ更新速報を発表しました。2026年6〜8月にエルニーニョ現象が発生する確率は80％とされ、少なくとも11月まで続く確率は90％超になると予測されています。WMOは「温暖化で温まった海洋と大気が、エルニーニョに伴う影響を増幅させている」と警告しています。

- 出典: [WMO: Prepare for El Niño](https://wmo.int/news/media-centre/wmo-prepare-el-nino)
- 出典: [El Niño confirmed, set to fuel more extreme weather, says WMO](https://news.un.org/en/story/2026/06/1167620)

### 2. 気象庁：防災気象情報の新たな運用開始（5月29日）

気象庁は5月29日、防災気象情報の運用を抜本的に更新しました。大雨・洪水・高潮の警報類と気象情報が再編され、5段階の警戒レベルに適した形でシンプル化されました。警報タイトルには「レベル3大雨警報」などの表記が採用され、レベル4には「危険警報」という呼称が新設されています。

- 出典: [防災気象情報 - Wikipedia](https://ja.wikipedia.org/wiki/防災気象情報)
- 出典: [気象庁報道発表資料](https://www.jma.go.jp/jma/press/)

### 3. 台風6号（チャンミー）の接近と大雨被害

南シナ海で発生した台風6号（チャンミー）が三重県熊野市付近を東進しており、東海地方を中心に非常に激しい雨が断続的に降っています。大雨災害への厳重な警戒が必要です。また、気象庁は線状降水帯予測システムの精度向上のため、海上の水蒸気観測を強化すると発表しています。

- 出典: [台風6号の影響と最新情報｜ウェザーニュース](https://www.tiktok.com/@kansya358aishiteru/photo/7646835111459147026)
- 出典: [気象・災害の最新ニュース一覧 | NHKニュース](https://www3.nhk.or.jp/news/saigai.html)

### 4. WMO：今後5年で記録的高温が続く可能性86％

WMOは5月28日、今後5年間の世界の平均気温が記録的な高水準で推移する可能性が高いと発表しました。観測史上最高気温を更新する年が出現する確率は86％とされています。また、CO2濃度は過去最高を更新し続けており、地球温暖化の加速に警鐘を鳴らしています。

- 出典: [WMO報告：今後5年で記録的高温が続く可能性](https://www.jircas.go.jp/ja/program/proc/blog/20260601)
- 出典: [Co2濃度が過去最高更新、さらなる異常気象の恐れ＝Wmo | ロイター](https://jp.reuters.com/markets/commodities/HGEHYZPR7FKO5MDLK3FT323WWU-2025-10-16/)

### 5. AI気象予報の進展：Google DeepMindのGenCastが性能向上

MITテクノロジーレビューによると、Google DeepMindのAI気象予報モデル「GenCast」が新たな性能向上を達成しました。チャットGPTと同様の仕組みで次に来る天候状態を予測するこの手法は、従来の数値予報モデルと比べて高速かつ高精度な予報を実現しています。

- 出典: [MIT Tech Review: Google DeepMind's New AI Model for Weather Forecasting](https://www.technologyreview.jp/s/351097/google-deepminds-new-ai-model-is-the-best-yet-at-weather-forecasting/)

### 6. エルニーニョ監視速報（No.404）：平常状態だがエルニーニョ傾向へ

気象庁のエルニーニョ監視速報（No.404、2026年4月実況）によると、太平洋赤道域は現在エルニーニョ・ラニーニャ双方が発生していない平常状態ですが、海面水温の基準値からの差は+0.7℃と高く、エルニーニョ現象時の特徴に近づきつつあります。

- 出典: [エルニーニョ監視速報（No.404）](https://www.data.jma.go.jp/cpd/elnino/kanshi_joho/kanshi_joho1.html)
- 出典: [エルニーニョ/ラニーニャ現象 令和8年5月25日更新](https://www.data.jma.go.jp/cpd/elnino/)

### 7. 気候変動：COP30がブラジル・ベレンで開催中

国連気候変動枠組み条約第30回締約国会議（COP30）がブラジル・ベレンで10日に始まりました。会場では「私たちの森は売り物ではない」といったスローガンの抗議活動も行われています。世界全体のCO2排出量は今年過去最大になる見通しです。

- 出典: [気候変動 - BBCニュース](https://www.bbc.com/japanese/topics/c2dwqjr27zjt)
- 出典: [気候変動 | 毎日新聞](https://mainichi.jp/climatechange/)

### 8. 「キキクル」通知サービスの拡大

気象庁の「キキクル」は、土砂災害や洪水災害からの自主避難を支援する危険度プッシュ型通知サービスです。警戒レベル4相当の「危険」（紫）への危険度高まりを、5つの事業者が実施しています。住民の主体的な避難判断を支援する目的で運用されています。

- 出典: [「キキクル」の通知サービスについて | 気象庁](https://www.jma.go.jp/jma/kishou/know/bosai/ame_push.html)
