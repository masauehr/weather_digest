# 気象ニュースダイジェスト（5/31〜6/7）

今週（5月31日〜6月7日）の気象・気候関連ニュースをまとめました。

## 1. WMO：エルニーニョ現象発生確率80％、9月以降は90％超に

世界気象機関（WMO）は6月初旬、エルニーニョ/ラニーニャ更新速報を発表しました。2026年6〜8月にエルニーニョ現象が発生する確率は80％とされ、少なくとも11月まで続く確率は90％超になると予測されています。WMOは「温暖化で温まった海洋と大気が、エルニーニョに伴う影響を増幅させている」と警告しています。

- 出典: [WMO: Prepare for El Niño](https://wmo.int/news/media-centre/wmo-prepare-el-nino)
- 出典: [El Niño confirmed, set to fuel more extreme weather, says WMO](https://news.un.org/en/story/2026/06/1167620)

## 2. 気象庁：防災気象情報の新たな運用開始（5月29日）

気象庁は5月29日、防災気象情報の運用を抜本的に更新しました。大雨・洪水・高潮の警報類と気象情報が再編され、5段階の警戒レベルに適した形でシンプル化されました。警報タイトルには「レベル3大雨警報」などの表記が採用され、レベル4には「危険警報」という呼称が新設されています。

- 出典: [防災気象情報 - Wikipedia](https://ja.wikipedia.org/wiki/防災気象情報)
- 出典: [気象庁報道発表資料](https://www.jma.go.jp/jma/press/)

## 3. 台風6号（チャンミー）の接近と大雨被害

南シナ海で発生した台風6号（チャンミー）が三重県熊野市付近を東進しており、東海地方を中心に非常に激しい雨が断続的に降っています。大雨災害への厳重な警戒が必要です。また、気象庁は線状降水帯予測システムの精度向上のため、海上の水蒸気観測を強化すると発表しています。

- 出典: [台風6号の影響と最新情報｜ウェザーニュース](https://www.tiktok.com/@kansya358aishiteru/photo/7646835111459147026)
- 出典: [気象・災害の最新ニュース一覧 | NHKニュース](https://www3.nhk.or.jp/news/saigai.html)

## 4. WMO：今後5年で記録的高温が続く可能性86％

WMOは5月28日、今後5年間の世界の平均気温が記録的な高水準で推移する可能性が高いと発表しました。観測史上最高気温を更新する年が出現する確率は86％とされています。また、CO2濃度は過去最高を更新し続けており、地球温暖化の加速に警鐘を鳴らしています。

- 出典: [WMO報告：今後5年で記録的高温が続く可能性](https://www.jircas.go.jp/ja/program/proc/blog/20260601)
- 出典: [Co2濃度が過去最高更新、さらなる異常気象の恐れ＝Wmo | ロイター](https://jp.reuters.com/markets/commodities/HGEHYZPR7FKO5MDLK3FT323WWU-2025-10-16/)

## 5. AI気象予報の進展：Google DeepMindのGenCastが性能向上

MITテクノロジーレビューによると、Google DeepMindのAI気象予報モデル「GenCast」が新たな性能向上を達成しました。チャットGPTと同様の仕組みで次に来る天候状態を予測するこの手法は、従来の数値予報モデルと比べて高速かつ高精度な予報を実現しています。

- 出典: [MIT Tech Review: Google DeepMind's New AI Model for Weather Forecasting](https://www.technologyreview.jp/s/351097/google-deepminds-new-ai-model-is-the-best-yet-at-weather-forecasting/)

## 6. エルニーニョ監視速報（No.404）：平常状態だがエルニーニョ傾向へ

気象庁のエルニーニョ監視速報（No.404、2026年4月実況）によると、太平洋赤道域は現在エルニーニョ・ラニーニャ双方が発生していない平常状態ですが、海面水温の基準値からの差は+0.7℃と高く、エルニーニョ現象時の特徴に近づきつつあります。

- 出典: [エルニーニョ監視速報（No.404）](https://www.data.jma.go.jp/cpd/elnino/kanshi_joho/kanshi_joho1.html)
- 出典: [エルニーニョ/ラニーニャ現象 令和8年5月25日更新](https://www.data.jma.go.jp/cpd/elnino/)

## 7. 気候変動：COP30がブラジル・ベレンで開催中

国連気候変動枠組み条約第30回締約国会議（COP30）がブラジル・ベレンで10日に始まりました。会場では「私たちの森は売り物ではない」といったスローガンの抗議活動も行われています。世界全体のCO2排出量は今年過去最大になる見通しです。

- 出典: [気候変動 - BBCニュース](https://www.bbc.com/japanese/topics/c2dwqjr27zjt)
- 出典: [気候変動 | 毎日新聞](https://mainichi.jp/climatechange/)

## 8. 「キキクル」通知サービスの拡大

気象庁の「キキクル」は、土砂災害や洪水災害からの自主避難を支援する危険度プッシュ型通知サービスです。警戒レベル4相当の「危険」（紫）への危険度高まりを、5つの事業者が実施しています。住民の主体的な避難判断を支援する目的で運用されています。

- 出典: [「キキクル」の通知サービスについて | 気象庁](https://www.jma.go.jp/jma/kishou/know/bosai/ame_push.html)

# 気象ニュースダイジェスト（5/31〜6/7）

## 1. 気象庁が新防災気象情報の運用を開始

気象庁と国土交通省は、2026年5月29日から新たな防災気象情報の運用を開始しました。この改革は、令和6年6月に取りまとめられた「防災気象情報に関する検討会」の提言に基づいています。

【主な変更点】
- 情報名称に警戒レベルの数字を付記し、市町村の避難指示との関係を明確化
- 「危険警報」（警戒レベル5に相当）を新設
- 大雨、河川氾濫、浸水など4種類の災害に対応した5段階の警戒レベルを採用
- 住民がとるべき避難行動との関連が分かりやすくなる

この新体系により、避難指示等の避難情報と気象情報の整合性が向上し、より迅速かつ適切な避難判断が可能になります。

**出典：** 
- [気象庁 - 新たな防災気象情報について](https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/index.html)
- [ウェザーニュース - 気象庁 新たな防災気象情報運用開始](https://weathernews.jp/news/202605/200171/)

## 2. WMO、今後5年間の記録的高温を予報

世界気象機関（WMO）は2026年5月28日、重要な気候予測を発表しました。今後5年間（2026～2030年）における世界の気候見通しについて、以下の警告を示しています：

【WMOの予測内容】
- 世界平均気温は今後5年間、記録的な高水準で推移する可能性が高い
- この期間中に観測史上最高気温を更新する年が出現する確率は**86%**
- 2026～2030年のいずれかの年に、産業革命前比で一時的に1.5℃を超える可能性も指摘

さらに、WMOは地球のエネルギー不均衡が拡大していると報告し、気候変動への強い危機感を表明しています。

**出典：** 
- [国立研究開発法人農研機構 - 今後5年で記録的高温が続く可能性、WMOが報告](https://www.jircas.go.jp/ja/program/proc/blog/20260601)
- [ウェザーニュース - 地球のエネルギー不均衡が拡大](https://weathernews.jp/news/202603/250106/)

## 3. 台風6号（チャンミー）が日本列島に接近

台風第6号「チャンミー」は日本列島に接近し、複数地域で大雨警報が発表されました。5月30日時点での気象庁の予報では：

【進路予想】
- 6月1日：沖縄・奄美地方にかなり接近
- 6月3日にかけて暴風域を伴ったまま西日本〜東日本に接近する見通し
- 強い勢力を保ったまま日本列島を通過

【被害情報】
- 宮崎県の広渡川水系広渡川では「レベル4氾濫危険警報」が発表
- 線状降水帯による局所的な豪雨のリスクも存在

住民は気象庁とウェザーニュースの最新情報に注視し、早期の避難判断が重要です。

**出典：** 
- [気象庁 - 台風や大雨に関する最新の防災気象情報](https://www.jma.go.jp/jma/bosaiinfo/rain_portal.html)
- [日本気象協会 tenki.jp - 台風6号情報](https://tenki.jp/lite/bousai/typhoon/2606/)

## 4. Google、AI気象予報モデル「WeatherNext 2」を発表

Google傘下のDeepMindは、新世代のAI気象予報モデル「WeatherNext 2」を発表しました。このモデルは気象予報の精度と速度を大幅に向上させています：

【WeatherNext 2の特徴】
- **速度：** 従来モデルの8倍速で気象予報を生成
- **解像度：** 最大1時間までの高解像度予報を実現
- **精度：** 高効率・高精度・高解像度の地球規模での天気予報を実現
- **適用範囲：** サプライチェーン、航空路、日常の移動など幅広い領域の意思決定を支援

Google以外にも、気象庁がGraphCastなどのAI気象モデルの利用可能性を調査中であり、今後、従来の数値予報モデルとAI気象モデルの組み合わせにより、気象予測の高精度化が期待されています。

**出典：** 
- [LEDGE.AI - Google、気象予報AI「WeatherNext 2」を発表](https://ledge.ai/articles/weathernext_2_google_ai_weather_forecasting_model_release/)
- [MyNavi Tech+ - 新時代のAI気象予報モデル「WeatherNext 2」登場](https://news.mynavi.jp/techplus/article/20251126-3688068/)
- [気象庁 - 気象庁におけるAIの活用](https://www.jma.go.jp/jma/kishou/know/ai/ai.html)

## 5. 2026年上期、エルニーニョ現象の可能性が高まる

気象庁大気海洋部の最新予報では、2026年夏までにエルニーニョ現象が発生する可能性が高いと発表されています：

【エルニーニョ現象の予測】
- 発生確率：約90%
- 影響：日本は冷夏や暖冬になりやすい
- 太平洋赤道域の海面水温が平年より高い状態が続く予想

エルニーニョ現象は、世界的な異常気象（干ばつ、豪雨など）をもたらすため、今後の農業生産や水資源管理に大きな影響を与える可能性があります。

**出典：** 
- [tenki.jp - 今夏までにエルニーニョ現象が発生する可能性が高い](https://topics.smt.docomo.ne.jp/article/tenkijp/nation/tenkijp-38893)

## 6. 気象庁が世界の異常気象を周期的に監視・分析

気象庁は「世界の異常気象速報」として、世界各地の異常気象・気象災害に関する情報を週ごとに発表しています。また、月・季節・年ごとに異常気象をとりまとめて公表し、顕著な現象が発生した場合には随時情報を発表しています。

【監視対象】
- 広い範囲での高温・低温
- 社会的に影響が大きい多雨・少雨
- 気象災害や極端な気象現象

この週別情報は、世界の気候変動傾向の把握と防災対策の検討に活用されています。

**出典：** 
- [気象庁 - 世界の週ごとの異常気象](https://www.data.jma.go.jp/cpd/monitor/weekly/)
- [気象庁 - 世界の異常気象](https://www.data.jma.go.jp/cpd/monitor/extreme_world/index.html)

## まとめ

2026年5月31日～6月7日の1週間は、気象防災体制の大きな転換期となりました。気象庁の新防災気象情報運用開始により、防災情報がより分かりやすくなる一方で、台風6号の接近に伴う大雨・洪水リスクが高まっています。また、WMOによる記録的高温予報とGoogle、気象庁によるAI気象予報技術の進展により、気象観測・予報業務は大きなターニングポイントを迎えています。

エルニーニョ現象の可能性が高まる中、気象情報に関する正確な理解と早期の避難判断がこれまで以上に重要となります。
